# Arduino Tetris Game

Arduino Uno R3を用いて制作したテトリス風ゲームです。
OLEDディスプレイへの表示、ジョイスティック入力、回転ボタン、スコア表示、ゲームオーバー処理、ブザーによる音の反応を実装しました。

## 制作目的

ハードウェアとソフトウェアを組み合わせて、実際に遊べる小型ゲーム機を制作することを目的としました。
単に画面上でブロックを動かすだけでなく、操作したときの反応や音の鳴り方によって、遊ぶ人の高揚感や没入感が変わると考え、体験として楽しめることを意識しました。

## 使用部品

 Arduino Uno R3
 OLEDディスプレイ
 ジョイスティック
 ボタン
 ブザー

## 実装した機能

* OLED画面へのゲーム表示
* ジョイスティックによる左右移動・下移動
* ボタンによるブロック回転
* スコア表示
* ゲームオーバー処理
* ブザーによる効果音

## 工夫した点

限られた画面サイズとArduinoの処理能力の中でゲームとして成立するように、表示更新や入力処理、ゲーム状態の切り替えを工夫しました。
また、操作に対して画面や音が反応することで、プレイヤーが「動かしている」と感じられる体験を重視しました。

## 今後の改善予定

今後は7セグメントLEDを用いたスコア表示、効果音の追加、操作感の改善、筐体の作成などを行い、よりアーケードゲーム機らしい作品に発展させたいと考えています。
