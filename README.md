# Arduino Tetris Game

Arduino Uno R3を使用して制作した、テトリス風のオリジナルゲームです。

OLEDディスプレイ、ジョイスティック、7セグメントLED、ブザーなどを組み合わせ、操作・映像・音が連動する小型ゲーム機を制作しました。

## 制作目的

ハードウェアとソフトウェアを組み合わせ、実際に遊べるゲーム機を自分の手で制作することを目的としました。

単にゲームを動作させるだけでなく、操作に対する反応や音、画面表示など、遊ぶ人が楽しめる体験を実現することを意識しました。

## 使用部品

- Arduino Uno R3
- OLEDディスプレイ（SH1106 128×64）
- ジョイスティックモジュール
- 押しボタン
- 4桁7セグメントLED
- ブザー

## 実装した機能

- OLEDディスプレイへのゲーム画面表示
- ジョイスティックによるブロックの左右移動・下移動
- ボタンおよびジョイスティックのスイッチによるブロックの回転
- 次に出現するブロックのプレビュー表示
- 7セグメントLEDによるスコア表示
- ライン消去とスコア加算
- スコアに応じたブロックの落下速度の上昇
- ブザーによるBGM・操作音・効果音
- ゲームの状況に応じて動きや表情が変化するキャラクター
- タイトル画面・ゲームオーバー画面の表示

## 工夫した点

### 1. 操作性の改善

当初はボタンによる操作を中心に制作していましたが、実際に遊んでもらった際の意見を参考に、ジョイスティックによる操作を取り入れました。

また、操作に対する反応音を追加することで、ブロックを動かした際の手応えを感じられるようにしました。

### 2. 表示方法の工夫

ゲーム画面にはOLEDディスプレイを使用し、盤面だけでなく次のブロックやキャラクターも表示するようにしました。

さらに、スコア表示をOLED画面から独立させ、4桁7セグメントLEDに変更しました。これにより、ゲーム画面とスコアをそれぞれ確認できるようにしました。

### 3. ゲーム体験の向上

BGMや操作音、ライン消去時の効果音を追加しました。

また、ゲームの状況に応じてキャラクターの表情や動きを変化させることで、ゲームの進行に合わせて楽しめる演出を取り入れました。

## 使用したライブラリ

- Wire
- U8g2
- TimerOne

## 使用方法

1. Arduino Uno R3に各部品を接続します。
2. Arduino IDEで `tetorisu777.ino` を開きます。
3. 必要なライブラリをインストールし、Arduino Uno R3に書き込みます。
4. ジョイスティックまたはボタンを押してゲームを開始します。
